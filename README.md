# 🚀 Mentora - Client Side

Welcome to the frontend repository of **Mentora**. This is a modern, responsive web application built with Next.js, designed to connect mentors and mentees efficiently.

🔗 **Live Application:** [https://mentora-client-beta.vercel.app/](https://mentora-client-beta.vercel.app/)

## 🛠️ Tech Stack

This client-side application utilizes the following technologies:

- **Framework:** [Next.js](https://nextjs.org/) (React Framework)
- **Styling:** Tailwind CSS (for modern & responsive UI)
- **Icons:** React Icons
- **Backend Support:** Express.js
- **Database:** MongoDB
